The bigger pictur why java is WORA for that Java follows the WORA (Write Once Run Anywhere) principle. We write code in a .java file. The javac compiler converts 
the source code into bytecode stored in a .class file. This bytecode is platform independent. The JVM on each operating system converts the bytecode into machine-specific 
instructions and executes it. The JDK contains development tools such as javac, while the JRE contains the JVM and Java runtime libraries required to run Java applications.
To compile javac filename.java and to run java filename
